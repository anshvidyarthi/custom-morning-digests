## 🧬 Biotech / Longevity / Neurotech

**FDA pilots real-time clinical trial monitoring with AstraZeneca and Amgen** — On April 28 the FDA announced two proof-of-concept real-time clinical trials: AstraZeneca's Phase 2 TRAVERSE study in mantle cell lymphoma and Amgen's Phase 1b STREAM-SCLC trial in small-cell lung carcinoma, both streaming endpoint data to the FDA continuously via Paradigm Health's cloud platform. If adopted at scale, live FDA data access could compress review timelines and catch safety signals weeks earlier than current periodic submission schedules allow. **Neuralink's Blindsight vision implant moves toward first human** — Separate from Neuralink's N1 motor cortex program, Blindsight is a cortical visual prosthetic for patients who have lost both eyes and their optic nerves but retain an intact visual cortex. The device pairs camera-equipped glasses with the S2 implant to stimulate the visual cortex directly via electrical pulses; first-generation resolution will be coarse but is expected to sharpen as neural plasticity adapts. The first human implant is planned in collaboration with Cleveland Clinic Abu Dhabi, with additional recruitment sites in the US, Canada, and UK. [Neuralink](https://neuralink.com/trials/visual-prosthesis/) | [IEEE Spectrum](https://spectrum.ieee.org/neuralink-blindsight)

China's regulator has already granted conditional approval for the same regimen. ## 💻 Software Engineering

**TypeScript 7.0 Beta: Go-based compiler, 10x faster** — Microsoft released the TypeScript 7.0 Beta on April 21, built on a methodical port of the compiler from TypeScript to Go (Project Corsa). The headline numbers are concrete: the VS Code codebase (1.5M lines) compiles in 7.5 seconds with `tsgo` versus 78 seconds with `tsc` today. Native execution and shared-memory parallelism account for most of the gain, and the Go codebase is "structurally identical" to TypeScript 6.0's type-checking logic, minimizing behavioral regressions. Important caveats: the beta checks types but does not yet emit JavaScript, and custom transformers have not been ported. A stable release is projected for late June or early July. [TypeScript Blog](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0-beta/) | [GitHub](https://github.com/microsoft/typescript-go) | [Visual Studio Magazine](https://visualstudiomagazine.com/articles/2026/04/21/typescript-7-0-beta-arrives-on-go-based-foundation-with-10x-speed-claim.aspx)

**cPanel zero-day (CVE-2026-41940) exploited for 30+ days before patch** — A CVSS 9.8 authentication bypass in all supported versions of cPanel & WHM was being actively exploited as a zero-day from at least February 23. The vulnerability stems from CRLF injection in the login and session-loading path: an attacker manipulates the `whostmgrsession` cookie and injects raw `\r\n` characters via a malicious authorization header to gain unauthenticated root access. An emergency patch shipped April 28; a public PoC followed shortly after. Any unpatched cPanel instance should be treated as compromised. [Help Net Security](https://www.helpnetsecurity.com/2026/04/30/cpanel-zero-day-vulnerability-cve-2026-41940-exploited/) | [watchTowr Labs](https://labs.watchtowr.com/the-internet-is-falling-down-falling-down-falling-down-cpanel-whm-authentication-bypass-cve-2026-41940/)

**Vercel breach via OAuth supply-chain attack on employee's AI tool** — A Lumma Stealer infection at Context.ai (a third-party AI assistant used by a Vercel employee) gave attackers access to that employee's Google Workspace and then to their Vercel account, allowing enumeration and decryption of non-sensitive environment variables for a subset of Vercel customers. Core infrastructure, npm packages, and open-source projects (Next.js, Turbopack) were unaffected. The incident illustrates a pattern: employee-facing AI SaaS tools often hold OAuth tokens that inherit broad cloud access, making them high-value supply-chain targets with a small detection footprint. [Vercel](https://vercel.com/kb/bulletin/vercel-april-2026-security-incident) | [GitGuardian](https://blog.gitguardian.com/vercel-april-2026-incident-non-sensitive-environment-variables-need-investigation-too/)

Microsoft acquired 86-DOS from Paterson in 1981 for $75,000; it became the foundation for MS-DOS and eventually Windows. ## Worth a Deeper Look

**TypeScript 7.0 Beta and what 10x compiler speed actually changes**

The raw performance numbers are striking, but the more consequential shift is architectural. The current JavaScript-based `tsc` runs in the same process as the editor LSP, making parallelism awkward and memory-sharing impossible. The Go port changes both: `tsgo` can spin up parallel workers over shared memory, and native binary execution removes Node.js startup and GC overhead that makes large monorepo builds painful. For teams with multi-million-line TypeScript codebases — common at product companies running Nx or Turborepo monorepos — 60–90 second type-check cycles are a meaningful CI and editor latency problem. A 10x reduction is not incremental; it changes the architecture of what's practical to check inline.

The beta has important gaps that affect adoption timing. `tsgo` currently only type-checks — it does not emit JavaScript output. Custom transformers (used by many frameworks including older Angular and NestJS configurations) have not been ported, and not all compiler options are supported. Teams using Babel, SWC, esbuild, or Vite for emit are largely unaffected by the emit gap, but anyone relying on `tsc --emit` directly will need to wait for stable. Microsoft projects a release candidate a few weeks before the ~late June stable date.

The strategic read: Microsoft announced this port in March 2025 and shipped a functional beta in under 13 months for a compiler of non-trivial complexity. Choosing to port rather than rewrite — preserving structural identity with TypeScript 6.0's type semantics — minimizes regression risk and should smooth migration for toolchain authors. For teams evaluating whether to invest in TypeScript or whether the toolchain overhead is worth it, this removes one of the most credible ongoing objections.
