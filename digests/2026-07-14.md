## ⚡ AI Productivity

**Claude Enterprise ships admin analytics and spend controls** —

. 
The Microsoft 365 connector now goes beyond search: with write tools enabled, Claude can draft, send, and organize email, manage calendar events, update mailbox settings, and create and update files in OneDrive and SharePoint

**GitHub Copilot adds agent browser tools and parallel sessions** — 
GitHub shipped VS Code v1.123–1.127 throughout June and early July 2026, building on the Copilot experience with integrated browser tools, parallel sessions, clearer cost visibility, and sharper Autopilot behavior
. 
Agentic browser tools are now generally available, allowing agents to navigate pages, inspect content, capture screenshots, and validate web apps directly in VS Code
. 
The Agents window supports running sessions side by side, using multiple chats in one session, and grouping related sessions
. [GitHub Blog](https://github.blog/changelog/2026-07-08-github-copilot-in-visual-studio-code-june-2026-releases/)

**MCP 2026-07-28 release candidate removes protocol sessions** — 
The MCP 2026-07-28 release candidate delivers on the 2026 roadmap: a stateless core that scales on ordinary HTTP infrastructure, extensions including server-rendered UIs through MCP Apps and long-running work through the Tasks extension
. 
A remote MCP server that previously needed sticky sessions, a shared session store, and deep packet inspection at the gateway can now run behind a plain round-robin load balancer, route traffic on an Mcp-Method header, and let clients cache tools/list responses
. 
The final specification will be published on July 28, 2026
. [MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)

**MCP Enterprise-Managed Authorization extension goes stable** — 
The Model Context Protocol team promoted its Enterprise-Managed Authorization extension to stable status, adding a centralized way for organizations to control access to MCP servers through their identity provider, aiming to replace per-server consent prompts with a zero-touch flow
. 
The MCP team says the extension has been adopted by Anthropic, Microsoft, Okta, and a growing number of MCP servers
. [InfoQ](https://www.infoq.com/news/2026/07/mcp-ema-enterprise-auth/)

## Worth a deeper look

**Simon Willison documents subagent cost patterns** — 
Simon Willison stated on July 3, 2026: "For all coding tasks use your judgement to decide an appropriate lower power model and run that in a subagent," explaining that cost/efficiency matters because implementation work rarely needs the top-tier model; judgment, review, and synthesis stay with the main loop, and when a task is primarily writing/editing code, spawn an Agent with a model override (Sonnet for substantive implementation, Haiku for trivial/mechanical edits) and a self-contained prompt
. 
Willison reports he's getting a ton of work done and his Fable allowance is shrinking less quickly than before
. 
He documented using GPT-5.6 Sol xhigh Codex to implement new strict table features, with one useful prompt telling the model to manually test its work using uv run python -c, effectively telling the model to manually test its work outside of automated tests, which turned up two minor issues
. [Simon Willison's Weblog](https://simonwillison.net/)
