## ⚡ AI Productivity

**SpaceX completes Cursor acquisition, Origin code hosting launches** — 
SpaceX completed its $60 billion acquisition of AI coding startup Cursor on August 14, according to a regulatory filing, two months after formally announcing the deal
. 
Cursor launched Origin this week—a code-hosting platform with repos, pull requests, code browsing, and GitHub sync, rolling out in early beta on all paid plans starting August 17
. 
Origin went live to paying customers on August 17, the same day GitHub suffered a multi-hour global outage
. [TechCrunch](https://techcrunch.com/2026/08/18/cursor-capitalizes-on-github-frustration-launches-rival-hosting-platform/)

**Cursor adds mid-agent steering, no interruption** — 
Cursor's August 19 changelog added the ability to send messages that steer the agent while it's working without interruption—follow-ups now wait for the next tool call instead of cutting the agent off mid-action, triggered by typing a follow-up and pressing Enter twice
. 
Cursor also added Grok 4.5 and Composer models, with always-on cloud agents that build, test, and ship code
. [Cursor](https://cursor.com/changelog)

**Anthropic ships MCP 2026-07-28 with stateless core** — 
Anthropic released the 2026-07-28 MCP specification last week, a major update and architectural redesign of how the protocol works, how servers scale, and how clients talk to tools
. 
Claude expanded support for the new spec, bringing a stateless core, stronger OAuth and OIDC authorization, and versioned extensions for Apps and Tasks—the connectors directory now lists over 950 MCP servers
. 
The new stateless protocol core runs on standard, scalable infrastructure without managing sessions, and the spec reduces the complexity developers manage
. [Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

**Cloudflare launches Kitesurf, agent-first browser** — 
Cloudflare launched Kitesurf, a cloud-hosted browser designed specifically for AI agents rather than a Chrome alternative for consumers
. 
Kitesurf is a stateless, highly scalable browser that runs entirely on top of Workers and uses 3–7× less CPU and memory than Chromium for common agentic tasks like screenshots and HTML extraction
. 
Memory consumption during HTML extraction is just 1/7th that of Chromium, and CPU usage is also less than 1/3rd
. 
The browser is available for free while in beta
. [Cloudflare Changelog](https://developers.cloudflare.com/changelog/post/2026-08-06-kitesurf/)

**GitHub Copilot ships Agent Plugins 1.0, adds new models** — 
GitHub Copilot shipped Agent Plugins 1.0, now generally available in VS Code, Copilot CLI, the GitHub Copilot SDK, and the Copilot app—developers can build a plugin once and use it across compatible agent tools
. 
Kimi K3 rolled out to Copilot Pro, Pro+, Max, Business, and Enterprise plans, while MAI-Code-1.1-Flash added native image understanding and improvements to coding quality, instruction following, tool use, and performance
. 
Grok 4.6, xAI's latest reasoning model, is now rolling out in GitHub Copilot and is designed for agentic coding and complex multi-step workflows
. [GitHub Changelog](https://github.blog/changelog/2026-08-13-github-copilot-weekly-releases-august-10/)

**Raycast 2.0 exits beta with AI and MCP upgrades** — 
Raycast released 2.0 out of beta, replacing v1 with a smoother upgrade path, preserved beta data, optional v1 import, and Pro access for Dictation and AI Chat—it also adds new AI and MCP features and boosts performance
. 
The update added loopback OAuth redirects so MCP providers that reject custom URL schemes, such as Atlassian, can now be connected, plus clearer error messages that show potential actions like retry or change model
. [Releasebot](https://releasebot.io/updates/raycast)

**Notion adds Custom Agent meeting triggers, MCP protocol upgrade** — 
Notion added Custom Agent triggers that run after an AI Meeting Note finishes, helping teams automate post-meeting work like updating trackers, sharing recaps, and turning feedback into tickets
. 
The Notion MCP endpoint at https://mcp.notion.com/mcp now supports MCP protocol version 2026-07-28, with existing clients that negotiate the earlier 2025-era protocol continuing to work unchanged
. 
Notion also added a Developer section to manage Workers, connections, tokens, view logs, and copy API IDs in one click
. [Releasebot](https://releasebot.io/updates/notion)

**Zed adds Gemini 3.6 Flash, agent sandboxing** — 
Zed added Gemini 3.6 Flash to Google AI models, plus Claude Opus 5, Gemini 3.5 Flash Lite, Gemini 3.6 Flash, Gemini 3.7 Flash, Kimi K3, Grok 4.6, and Muse Spark 1.2 to OpenCode Zen
. 
Zed supports sandboxing to restrict what agents can do while using the terminal and fetch tools, announced August 12, 2026
. 
Zed announced Delta, a multiplayer environment for coding with AI agents, entering private beta—the focus shifts toward creating the optimal environment for discussing code
. [Zed Release Notes](https://releasebot.io/updates/zed)

**Mastra ships file-based schedules, Oracle support, QuickJS sandbox** — 
Mastra's August 12 release added file-based agents that can declare recurring tasks via a schedules/ directory, syncing to schedule storage at startup and eliminating runtime registration code, plus @mastra/oracledb with OracleStore for composite storage and OracleVector for Oracle 23ai+ deployments
. 
A new @mastra/quickjs transport runs model-authored programs in an in-process QuickJS WASM runtime without a full sandbox, enabling Code Mode on more serverless hosts
. 
Mastra is an open-source TypeScript framework for building AI-powered applications and agents, providing agents, workflows, memory, workspaces and observability
. [Mastra GitHub](https://github.com/mastra-ai/mastra/releases)

## Worth a deeper look

**Cursor Origin and the post-GitHub world** — 
Cursor launched Origin, a native code hosting platform that brings repositories, pull requests, reviews, merges, and CI connections directly into Cursor, putting the AI coding company into territory long dominated by GitHub and signaling that it sees its future extending far beyond the AI code editor that made it famous
. 
Cursor pushed its AI coding tools past the editor this week, shipping an early beta of Origin, which went live to paying customers on August 17—the same day GitHub suffered a multi-hour global outage
. 
Origin arrives just days after SpaceX officially completed its $60 billion all-stock acquisition of Cursor on August 14, two months after announcing the deal, bringing one of the fastest-growing AI coding companies under Elon Musk's SpaceX
. The timing signals a broader shift: coding agents need infrastructure built for agent-scale version control, not bolt-on AI features in human-centric tools. [TechStartups](https://techstartups.com/2026/08/17/cursor-launches-origin-a-github-rival-built-for-ai-coding-agents/)
