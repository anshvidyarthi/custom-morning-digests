## ⚡ AI Productivity

**GitHub Copilot CLI adds prompt recall and session resume** — 
Copilot CLI adds smarter prompt recall, faster session resume, and broader MCP reliability, along with improved worktree path customization and Windows sandbox proxies
. 
Consecutive steering prompts in the same mode now combine into one pending message, you can press Up in an empty chat input to recall and edit previous prompts, and Ctrl+C stops the running turn instead of removing pending prompts
. [GitHub Release Notes](https://releasebot.io/updates/github)

**GitHub Copilot code review goes multi-agent** — 
Copilot code review now resolves addressed comments during subsequent reviews, suggests commit messages when you apply code suggestions, and reviews can use shell tools to validate changes while Lite reviews combine findings from multiple agents
. 
The new efficiency, balance, and intelligence tiers in auto model selection let you choose how Copilot weighs cost, quality, and response time, rolling out across VS Code, Copilot CLI, and the Copilot app
. [GitHub Changelog](https://github.blog/changelog/2026-09-18-github-copilot-weekly-releases-september-14/)

**Claude Managed Agents ships auto-evaluation mode** — 
Claude Managed Agents permission policies now include auto: the server evaluates each agent or MCP tool call and runs it, denies it, or pauses for your approval, with evaluation results reported in agent.tool_use and agent.mcp_tool_use events
. 
Version 1.32.0 of the ant CLI adds `ant beta:sessions connect`, which attaches your terminal to a Claude Managed Agents session where you can follow the session live, send messages, and allow or deny tool calls, or pass --web to serve the Claude Console's session viewer locally
. [Anthropic Release Notes](https://releasebot.io/updates/anthropic/claude-developer-platform)

**Vercel CLI hits sub-second deployments** — 
Vercel CLI now supports sub-second artifact deployments for static content, enabling both developers and AI agents to deploy in under one second—a significant speed improvement for rapid iteration workflows
. 
Secure Compute and Static IP builds now start 64% faster, dropping average startup time from 6.7 seconds to 2.4 seconds—a major performance gain for enterprise deployment workflows requiring security and predictable networking
. [Vercel Community](https://community.vercel.com/t/vercel-weekly-2026-09-21/49532)

**OpenAI Agents SDK adds sandbox execution and file harness** — 
The updated Agents SDK helps developers build agents that can inspect files, run commands, edit code, and work on long-horizon tasks within controlled sandbox environments, introducing standardized infrastructure with a model-native harness and native sandbox execution
. 
The harness now has configurable memory, sandbox-aware orchestration, Codex-like filesystem tools, and standardized integrations with primitives that are becoming common in frontier agent systems, including the apply_patch tool and more
. [OpenAI](https://openai.com/index/the-next-evolution-of-the-agents-sdk/)

**Notion introduces Skills for agent workflow sharing** — 
Agents can now capture ideas and draft content in Notion without choosing placement first as private drafts, and when you ask your AI to save a workflow you want to reuse, it can create a Notion Skill or turn an existing page into one—Skills are reusable instructions stored as Notion pages that you own and can edit, and when you ask for that workflow later, your AI can find the right Skill and read its instructions before starting
. [Notion Release Notes](https://releasebot.io/updates/notion)

**Notion Skills export to local coding agents** — 
You can take skills with you no matter what agent you use: create and update the skill in Notion, then download it to Claude Code, Codex, Cursor, Gemini, or Grok as Notion writes the skill as a SKILL.md file along with approved supporting files, and your team maintains the instructions in one place while your local agents follow the same process
. [Notion Releases](https://www.notion.com/releases/2026-09-15)

**Zed ships tabular data previews and Git improvements** — 
Zed ships tabular data previews for CSV, TSV, PSV, and SSV files with sortable and resizable columns plus value-based row filtering, new Git blame and stashing actions, and lower memory use when opening large files
. 
The editor added an ask_user tool that lets the Agent ask questions through forms with selectable options or free-text input, plus editor: blame revision and editor: blame previous revision actions for viewing a file's blame at the selected revision, and Stash Tracked and Stash Staged options to the Git Panel
. [Zed Release Notes](https://releasebot.io/updates/zed)

**Raycast deepens Linear and Notion integrations for 2026** — 
Raycast's built-in integrations expanded in 2026 with Linear 2.0 integration that creates, searches, and updates Linear issues directly from the command palette with understanding of your project structure, plus Notion database support that queries and updates Notion databases without opening Notion, letting you filter, sort, and edit records inline
. [Raycast Updates](https://raycast-discount-code.com/blog/raycast-2026-updates)

## Worth a deeper look

**Simon Willison's agentic engineering patterns consolidate around knowledge hoarding** — In a February 2026 newsletter entry, Simon Willison outlined a core pattern for working productively with coding agents: "hoard things you know how to do." 
A big part of the skill in building software is understanding what's possible and what isn't, and having at least a rough idea of how those things can be accomplished; these questions can be broad or quite obscure—can a web page run OCR operations in JavaScript alone, can an iPhone app pair with a Bluetooth device even when the app isn't running, can we process a 100GB JSON file in Python without loading the entire thing into memory first
. This maps cleanly to the shift from "writing code" to "directing agents": domain knowledge about what's technically feasible becomes the differentiator, not syntax recall. Willison's emphasis on building a mental library of capabilities is now the scaffolding for effective agent delegation. [Simon Willison's Newsletter](https://simonw.substack.com/p/agentic-engineering-patterns)
