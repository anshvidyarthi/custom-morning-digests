## ⚡ AI Productivity

**GitHub Copilot CLI metrics improved** — 
GitHub improved Copilot usage metrics API with CLI now reporting suggested lines of code, better IDE identification for server-side telemetry users, and more accurate AI credit attribution
. The update fixes previously incomplete CLI activity reporting that always showed zero suggested lines. [Releasebot](https://releasebot.io/updates/github)

**Kimi K2.7 Code launches as first open-weight Copilot model** — 
Kimi K2.7 Code is now generally available in GitHub Copilot as the first open-weight model in the picker, giving users a lower-cost option for coding workflows
. 
The model is hosted by GitHub on Microsoft Azure and billed at provider list pricing under usage-based billing
. It's rolling out to Copilot Pro, Pro+, and Max plans first with Business and Enterprise to follow. [GitHub Changelog](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/)

**Copilot Vision ships with image and PDF support** — 
Copilot Vision is now generally available, allowing users to attach images and PDFs directly to chat prompts so Copilot can reason about what it sees alongside code across all Copilot subscribers: Free, Pro, Pro+, Business, and Enterprise
. No policy changes or admin actions required—it's on by default. [GitHub Changelog](https://github.blog/changelog/2026-07-01-copilot-vision-is-generally-available/)

**GitHub adds AI credit pools for cost centers** — 
GitHub adds AI credit pools for cost centers, letting enterprises cap how much of their monthly included Copilot AI credits each cost center can use through the REST API today, with UI management coming soon
. This prevents one cost center from consuming credits that other teams' licenses funded. [Releasebot](https://releasebot.io/updates/github)

**MCP 2026-07-28 release candidate goes stateless** — 
The 2026-07-28 MCP specification delivers a stateless core that scales on ordinary HTTP infrastructure, extensions framework, Tasks extension, MCP Apps, and authorization hardening, with the final specification shipping on July 28, 2026
. 
Remote MCP servers can now run behind a plain round-robin load balancer without sticky sessions or shared session stores, routing on Mcp-Method headers
. [Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)

**Apple ships Safari MCP server for agents** — 
Apple released the Safari MCP server on July 1, 2026 with Safari Technology Preview 247, the first official browser MCP integration from a major browser vendor that gives AI coding agents direct access to Safari's Web Inspector to emulate what users experience on a website
. The server lets agents inspect pages, capture screenshots, evaluate JavaScript, and run accessibility checks directly in Safari. [Developers Digest](https://www.developersdigest.tech/blog/safari-mcp-server-developer-guide-2026), [MacRumors](https://www.macrumors.com/2026/07/01/apple-releases-safari-technology-preview-247/)

**Notion AI usage surges with MCP integrations** — 
Notion MCP usage has 10×'d in the past month, with Custom Agents gaining five more connections out of the box: Mercury, Mixpanel, Miro, Box, and ClickHouse, joining connections like Figma, GitHub, and Zapier
. 
Notion expands AI agents with shared multi-agent workflows, allowing multiple agents into a single UI to automate entire workflows end-to-end
. [Releasebot](https://releasebot.io/updates/notion)

**Notion launches Workers for custom code** — 
Notion Workers are the company's hosted runtime for custom code, letting users extend Notion without running their own servers by writing code that deploys through the CLI and runs in a secure sandbox, free during beta until August 11 2026
. Database sync, agent tools, and webhook triggers all run on this new primitive. [Releasebot](https://releasebot.io/updates/notion)

## Worth a deeper look

**MCP goes production-ready with breaking changes** — The Model Context Protocol's July 28 specification is the most significant revision since launch, eliminating the initialize handshake and session-based architecture that created deployment headaches. 
The 2026-07-28 release candidate eliminates Mcp-Session-Id, the initialize handshake, and sticky routing requirements, with teams having until July 28 to migrate as servers that relied on session headers will need to read protocol version from _meta and implement server/discover
. 
As of July 2026, 78% of enterprise AI teams have MCP-backed agents in production, 28% of Fortune 500 companies run MCP servers, and monthly SDK downloads sit at ~97 million
. The shift to stateless HTTP means MCP servers can finally scale like normal web services. [byteiota](https://byteiota.com/mcp-goes-stateless-july-2026-breaking-changes/), [andrew.ooo](https://andrew.ooo/answers/mcp-model-context-protocol-enterprise-adoption-july-2026/)
