## ⚡ AI Productivity

**GitHub Copilot CLI redesign reaches general availability** — 
The redesigned terminal interface for GitHub Copilot CLI that was previewed at Microsoft Build 2026 is now generally available
. 
You get a tabbed layout for working with GitHub directly from your terminal, a new experience for configuring your tools, and a cleaner, more accessible interface throughout. An interactive Copilot CLI session now has tabs at the top of the screen. Press Tab to move between the default Session tab and a Gists tab for your personal gists. When you run the CLI inside a GitHub repository, you also get Issues and Pull requests tabs for that repository
. [GitHub Changelog](https://github.blog/changelog/2026-06-23-copilot-cli-new-terminal-interface-is-generally-available/)

**Copilot CLI adds voice input and rubber duck code review** — 
Copilot CLI now includes hands-free dictation. Hold the space bar on your keyboard and talk to input a prompt. Alternatively, press Ctrl+X followed by V to start recording, speak your prompt, then press any key to stop recording and insert the transcription
. 
Rubber duck is a built-in CLI agent that acts as a constructive critic. While working on a task, the main CLI agent for a session can pass its current plan, design, implementation, or tests over to the rubber duck agent for review. The rubber duck agent looks for blind spots, design flaws, and substantive issues, and reports back with concrete, actionable feedback. Copilot then takes that critique into account before continuing
. [GitHub Changelog](https://github.blog/changelog/2026-06-02-copilot-cli-improved-ui-rubber-duck-prompt-scheduling-and-voice-input/)

**Replit ships Agent 4 and Security Agent for whole-codebase security audits** — 
Agent 4 is here. Built for creativity, Agent is your AI creative partner - turning your ideas into apps, designs, slides, and more, all from plain language
. 
Security Agent is a new AI-powered reviewer that audits not just your dependencies, but your entire project. It builds a threat model, maps your routes and data flows, runs static analysis with Semgrep and HoundDog.ai, and uses an LLM to decide which findings are actually exploitable in the context of your app. When the review finishes, Security Agent organizes the accepted findings into parallel tasks that Replit Agent can fix in one pass
. [Releasebot](https://releasebot.io/updates/replit)

**Notion shuts down Notion Mail, says AI agents made inbox obsolete** — 
Notion is shutting down Notion Mail on September 22, less than 18 months after making the email product available to users. The company said the decision reflects a broader shift in how people interact with email, with AI agents increasingly handling triage, responses, and scheduling without requiring anyone to open an inbox
. 
More than half of Notion Mail's users manage their email without ever opening the inbox view, according to a post the company published on X
. [The Next Web](https://thenewstack.io/notion-mail-shuts-down-ai-agents-email-productivity)

**Claude Code adds `/rewind` and slashes CPU overhead** — 
Claude Code adds `/rewind` to resume conversations before `/clear`, improves MCP reliability and OAuth retries, and cuts CPU use during streaming by about 37%
. The update also fixes several agent, permissions, terminal, and login issues. Meanwhile, 
Anthropic has deprecated fast mode for Claude Opus 4.7, with removal on July 24, 2026. After removal, requests to claude-opus-4-7 with speed: "fast" will return an error
. [Releasebot](https://releasebot.io/updates/anthropic)

**AI coding tool pricing reshuffles in June** — 
Cursor announced a Teams update in June 2026: Standard seats now split usage into two pools - Composer/Auto (first-party Cursor models including Composer 2.5) and Third-Party API (Claude, GPT, Gemini). A new Premium seat tier (5x usage, 3x cost at $120/seat/month) covers developers running agents all day. Cursor estimates these changes lower costs for 90% of teams
. 
GitHub Copilot Free includes 2,000 code completions per month and basic Copilot CLI access at no cost. Cursor Hobby and Windsurf/Devin Free both offer unlimited Tab completions with limited agent quota
. [Developers Digest](https://www.developersdigest.tech/blog/ai-coding-tools-pricing-june-2026)

**Anthropic gives California 50% discount on Claude for all state agencies** — 
Anthropic will reportedly give California government workers expanded, discounted use of its Claude AI products. The new arrangement follows a deal between the artificial intelligence company and California Gov. Gavin Newsom, and makes Claude the first AI tool available to all state agencies and local governments
. 
The goal is to increase adoption of Claude by reducing the chatbot's price for government agencies and municipalities by half. The deal also includes free workforce training and technical support from Anthropic
. [PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/anthropic-gives-california-government-a-discount-on-claude/)

**Claude in Microsoft Foundry reaches general availability** — 
Claude launches generally available in Microsoft Foundry on Azure, bringing Azure-native access with existing identity, billing, governance, and optional US data zone support. Claude Opus 4.8 and Claude Haiku 4.5 are available in the Messages API for coding, agentic work, and complex reasoning
. 
Claude runs in your Azure environment with the authentication, billing, and governance controls your teams already use. You can choose where inference is processed, including a US data zone for teams with data residency requirements
. [Releasebot](https://releasebot.io/updates/anthropic/claude)
