## ⚡ AI Productivity

**Cursor Projects: The Multi-Month Agent Workspace** — 
Cursor launched Projects, a workspace for larger coding efforts that maintains context over months, delegates to thousands of subagents, and performs recurring work without prompts
. 
The coordinator agent plans work, delegates to implementation agents, and runs as many in parallel as needed
. 
Projects run on their own cloud computer, watch Slack channels or schedules, and can take action on signals without waiting for prompts—like auto-delegating bug reports from a monitored channel
. [Cursor](https://cursor.com/changelog)

**GitHub Copilot's September Model Orchestration Push** — 
GitHub Copilot introduced Jira integration in the Copilot app and Project HydraFusion in CLI—an adaptive model orchestrator that automatically routes tasks between local, cloud, and compound models to balance performance, cost, and latency
. 
The September 7 update also added scheduled agent automations for recurring tasks, experimental voice mode for interrupting agents mid-work, and in-Agents-window PR/issue review without opening the full repo
. 
MAI-Code-1-Flash was deprecated across all Copilot experiences on September 10
. [GitHub Blog](https://github.blog/changelog/2026-09-10-github-copilot-weekly-releases-september-7/)

**Anthropic Ships `ant apply` for Infrastructure-as-Code Agents** — 
Version 1.30.0 of the ant CLI adds `ant apply`, which creates and updates agents, environments, skills, memory stores, and deployments from files in your repository—describe each resource in a file, run ant apply, approve the plan, and commit the lockfile it writes
. This enables 
GitOps-style management where later runs update the same resources instead of creating new ones
. [Anthropic Release Notes](https://releasebot.io/updates/anthropic)

**Windsurf Becomes Devin Desktop with Agent-First Redesign** — 
Windsurf rebranded to Devin Desktop on June 2, 2026, making the Agent Command Center the default surface—a Kanban view managing every local and cloud agent from one place
. 
Devin Local, a Rust rewrite of Cascade, is the new primary local agent—up to 30% more token-efficient and supports subagents; legacy Cascade remains available through July 1
. 
Devin Desktop launched with support for the Agent Client Protocol (ACP), allowing Codex, Claude Agent, OpenCode, and other ACP agents to run inside with the same Kanban interface
. [Devin](https://devin.ai/blog/windsurf-is-now-devin-desktop)

**Replit Adds Model Choice and Scheduled Backups** — 
Replit added scheduled backups creating one daily restore point for production databases, with retention limits depending on plan tier
. 
Project Analytics shows visitor trends, traffic sources, countries, browsers, and devices for published apps, with paid plans enabling custom events and funnel analysis via Agent
. 
Users can now choose Agent's primary model, expanded MCP server connections include Cal.com, Airtable, and Rootly Docs, and a rebuilt Usage page shipped alongside extended sign-in sessions
. [Replit Release Notes](https://releasebot.io/updates/replit)

**ReleasePad MCP Server for Changelog Automation** — 
ReleasePad launched an MCP server on September 14 letting AI agents draft, publish, and analyze product changelogs—agents can read merged work, write customer-ready notes, file them by category, attach images, and schedule publication, all via OAuth with no API keys
. 
Every draft waits for human approval before publishing; entries reach users in-app via a 4.3kb widget, on a public changelog page, and as an LLM-ready Markdown feed
. 
The server is included in ReleasePad Pro at $35/product/month with unlimited team members
. [Globe Newswire](https://www.globenewswire.com/news-release/2026/09/14/3361396/0/en/releasepad-launches-mcp-server-so-ai-agents-can-draft-publish-and-measure-product-changelogs.html)

**Vercel v0 and Agent Reach Production Grade** — 
Vercel rebuilt v0 from the ground up with a sandbox runtime that imports GitHub repos, auto-pulls environment variables and configs from Vercel, and generates production-ready code that lives in your repo
. 
A new Git panel creates branches per chat, opens PRs against main, and maps previews to real deployments—enabling non-engineers to ship production code through proper git workflows
. 
Agents now account for more than half of Vercel deployments, up from under 3% six months ago; token volume through AI Gateway grew from two trillion to twenty trillion per month
. [Vercel Blog](https://vercel.com/blog/introducing-the-new-v0)

**MCP Servers Move to OAuth 2.1 Under 2026-07-28 Spec** — 
The MCP 2026-07-28 release candidate delivers a stateless core that scales on HTTP infrastructure, extensions including server-rendered UIs and long-running tasks, and authorization aligned with OAuth and OpenID Connect
. 
A remote MCP server that previously needed sticky sessions and shared state can now run behind a plain round-robin load balancer and route on Mcp-Method headers
. 
The final specification published on July 28, 2026
. 
Docusign announced its MCP Server will go generally available globally on September 30, joining Salesforce and ServiceNow in the enterprise MCP push
. [MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)

**LangGraph Leads, AutoGen in Maintenance, CrewAI Growing** — 
AutoGen 1.0 reached GA in February 2026 with v2 event-driven architecture; old v0.2 code does not run unmodified on 1.0
. 
Microsoft moved active development to the Microsoft Agent Framework (1.0 shipped April 2026), leaving AutoGen in maintenance mode
. 
LangGraph offers explicit state graphs with checkpointing, streaming, and human-in-the-loop; CrewAI ships role-based multi-agent crews with minimal code
. 
LangGraph costs $63/month at 1,000 daily runs versus $78–$102 for CrewAI and $84–$171 for AutoGen due to token efficiency
. [PE Collective](https://pecollective.com/blog/ai-agent-frameworks-compared/)

## Worth a deeper look

**Simon Willison on Coding Agents Crossing the Reliability Threshold** — 
Simon Willison notes that both Anthropic and OpenAI spent 2025 training for code after Claude Code launched in February, and November 2025 was the tipping point when coding agents became reliable partners—agents can now be trusted to produce working code 9 out of 10 times
. 
Many of his peers now say 70–80% of the code they produce is written by coding agents
. 
Willison argues coding agents basically didn't work before December 2025 and basically work since—models have significantly higher quality, long-term coherence, and tenacity to power through large tasks well past enough to disrupt the default programming workflow
.
